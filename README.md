# CHAOSCREW ONLINE — העלאה לשרת

## מה יש בחבילה
- `server.js` — שרת Node.js + WebSocket
- `public/index.html` — המשחק בדפדפן
- `package.json` — התלויות
- `README.md` — הוראות

## הדרך הפשוטה ביותר: Render / Railway / VPS
השרת צריך Node.js 18+.

1. העלו את כל התיקייה ל-GitHub.
2. צרו Web Service חדש אצל ספק Node.js.
3. Build/Install command:
   `npm install`
4. Start command:
   `npm start`
5. פתחו את כתובת האתר שקיבלתם.
6. שתפו אותה עם החברים.

## משחק ממכשירים שונים
אחד לוחץ "יצירת חדר".
הוא מקבל קוד חדר.
כל חבר פותח את האתר בטלפון שלו, לוחץ "הצטרפות", ומכניס את הקוד.
כל המכשירים מחוברים לאותו שרת WebSocket ולכן מצב החדר מסונכרן.

## חשוב
זו גרסת Online MVP מוכנה להרצה, לא מערכת Production סופית.
לפני שימוש ציבורי כדאי להוסיף:
- מסד נתונים אמיתי לפרופילים והיסטוריית החבורה
- מערכת התחברות/זהות
- שמירת חדר קבוע לכל חבורה
- moderation לתוכן שהחברים מוסיפים
- מערכת סודות/סיפורים עם הרשאות ופרטיות
- מערכת קוסמטיקה מלאה
- יותר מיני־משחקים
- reconnect במקרה של ניתוק
- rate limiting ואבטחת WebSocket
- HTTPS/WSS (רוב שירותי הענן מספקים זאת אוטומטית)

## מקומית
npm install
npm start

ואז לפתוח:
http://localhost:3000

כדי לשחק בין מכשירים שונים צריך להעלות לשרת ציבורי; localhost במחשב אחד אינו נגיש אוטומטית לטלפונים אחרים.
